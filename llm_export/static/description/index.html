How It Works

Ask → Export → Download

The odoo_export LLM tool lets your AI assistant generate a CSV file from any Odoo model and attach it directly to the conversation. The AI reads your natural language request, selects the right fields, applies filters, and delivers the file inline — without leaving the chat.

Example Conversation

“Export name, phone, email and country from our top 50 customers as CSV”

📎 res_partner_export.csv (50 records)
Exported name, phone, email, country_id — attached to this conversation.

Features

Everything the AI needs to export your data cleanly

Natural Language Fields

Say “name, phone, address” and the AI maps them to the correct Odoo field names automatically. No need to know technical field names.

Any Odoo Model

Export from res.partner, product.template, sale.order or any other model. Access is governed by the user’s own Odoo permissions.

Smart Filtering

Describe your subset in plain language — “active customers in France” — and the AI translates it into a proper Odoo domain filter.

Re-importable IDs

Relational fields (many2one, many2many) are exported as database IDs, not display names, so the file can be cleanly re-imported into Odoo without ambiguity.

Inline Attachment

The exported file appears as a downloadable attachment chip inside the AI chat thread — no redirects, no email, no external downloads page.

Format-Extensible

CSV is the default. The format-dispatch architecture makes adding XLSX, JSON, or any other format a simple one-method extension — no core changes needed.

Context Injection

The thread ID is injected server-side via env.context[‘message’] — the AI never needs to pass it explicitly.

Permission-Scoped

search_read runs as the calling user. Records and fields the user cannot access are never returned.
