TypeSafe Jev Decision API

Evaluate named predicates against structured JSON state with the LLM framework.

Configure the provider API key as an LLM Manager. The provider uses the installation company.

The caller must filter personal data before each request. This addon sends the supplied state and predicates to the API.

Resolve the stock API key access rules before production use. See the README for the API contract and tests.
