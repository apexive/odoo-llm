Dark Mode Backend Theme

A minimalist and elegant dark mode theme for Odoo 16 backend.

v16.0.1.0.0 LGPL-3 GitHub Repository

This module transforms the Odoo backend with a modern dark interface, reducing eye strain and providing a visually appealing experience for daily ERP users.

Overview

The Dark Mode Backend Theme module brings a sleek, modern look to your Odoo 16 backend. Designed for comfort and productivity, it is ideal for users who spend long hours working in Odoo.

  • Minimalist and elegant dark color palette
  • Compatible with standard Odoo modules
  • Easy installation and activation
  • Improved visual comfort for extended use

Installation

  1. Copy the dark_theme_backend folder into your Odoo addons directory.
  2. Activate developer mode in Odoo.
  3. Go to Apps, update the app list, and search for "Dark Mode Backend Theme".
  4. Install the module.
