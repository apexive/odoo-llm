# Dark Mode Backend Theme

This module provides a minimalist and elegant dark mode theme for the Odoo 16 backend.

## Features
- Modern and attractive dark mode interface
- Compatible with standard Odoo modules
- Easy to install and activate

## Installation
1. Copy the `dark_theme_backend` folder into your Odoo addons directory.
2. Activate developer mode in Odoo.
3. Go to Apps, update the app list, and search for "Dark Mode Backend Theme".
4. Install the module.

## Usage
Once installed, the Odoo backend will automatically display the new dark mode theme.
